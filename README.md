## The pitch

> We sell silence by the hour: soundproof pods in open offices where burnt-out workers pay $12 to sit alone, stare at a blank wall and do nothing — the one perk nobody has tried selling is nothing.

## How it works

`main.py` is deterministic: it writes that one sentence (195 characters, one line, one sentence) to `/output/entry.txt`. No time, no randomness, no input, no network.

```sh
python3 main.py
cat /output/entry.txt
```
